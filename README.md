# DRIVEKIT landing

Готовий односторінковий лендинг для DRIVEKIT GL-965A.

## Що вже є
- premium dark automotive design
- mobile-first
- реальні фото GL-965A з каталогу постачальника
- галерея товару
- scroll-анімації
- mobile sticky CTA
- швидка форма: ім’я + телефон + місто
- без акаунтів / реєстрації / корзини / складного checkout
- підготовка під Meta Pixel Lead event

## Як запустити локально
Відкрийте `index.html` у браузері.

## Як викласти на Vercel
Найпростіше:
1. Створити новий GitHub repo.
2. Завантажити туди всі файли з цієї папки.
3. Vercel → Add New Project → Import repo.
4. Framework Preset: Other.
5. Build Command: порожньо.
6. Output Directory: порожньо / root.
7. Deploy.

## Форма замовлення
Заявка відправляється лише через серверну функцію `/api/order.js` у Telegram.
Токен бота ніколи не передається у браузер і не повинен потрапляти в Git.

Повідомлення містить ім’я, телефон, місто, товар, ціну, UTM source/campaign,
referrer, URL сторінки та час за Києвом. Є базова серверна валідація,
honeypot від ботів і обмеження частоти запитів.

## Meta Pixel
У `app.js` вже є виклик:
`fbq('track', 'Lead')`

Він спрацює, коли Meta Pixel буде доданий у `<head>` сайту.

## Фото
Сайт використовує конкретні фото моделі GL-965A з `drops.in.ua`.
Перед комерційним запуском варто підтвердити у постачальника право використання фото у рекламі/лендингу.

## Кращий бойовий варіант: заявки у Telegram
У проекті є `/api/order.js`.

У Vercel → Project → Settings → Environment Variables додайте:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

Секрети не вставляйте у код і не комітьте. Зразок назв змінних є у `.env.example`.

Після додавання змінних зробіть новий Deploy. Без них endpoint навмисно повертає
помилку, а форма не показує неправдиве повідомлення про успішну заявку.

### Як отримати CHAT_ID
1. Додайте бота в потрібний канал або групу як адміністратора з правом публікувати.
2. Надішліть у канал/групу тестове повідомлення.
3. Відкрийте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` і знайдіть `chat.id`.
4. Для каналу ID зазвичай починається з `-100`.
